# مرجع UX: كوكباد (cookpad.com/es) — دراسة استئسار، لا استنساخ

- **الحالة:** مرجع تصميمي — لا قرار معماري (لا يحتاج ADR)
- **التاريخ:** 2026-11-03
- **المُخرِج:** طلب المالك رؤية الموقع كمرجع؛ حُسم بجواب المالك (2026-11-02) أن المسار **دراسة UX**: قراءة عامة لأنماط الموقع كواجهة للاستئسار، **بلا نسخ محتوى أو صور أو كود** — حقوق كتّاب الوصفات على مستودع مرخّص MIT تصطدم بالنسخ، وبند AGENTS §3.2 يمنع لصق مصدر شفرات خارجي خام.

## المنهجية

زيارة سطحية بمتصفح REA: الصفحة الرئيسية للمجهول، وصفحة نتائج بحث واحدة، وصفحة وصفة واحدة. ما يُدوَّن هنا **أنماط بنيوية عامة** (أسماء أقسام الأمور المشتركة، ترتيب عناصر، سلوك المجهول) — لا نصوص ولا صور ولا تخطيط بصري.

## القرار الإجرائي

1. **هذه الوثيقة** لا تجيز بناء شيء بذاتها — كل بند من الجدول يحتاج Issue يفتح به المقترح ومعيار نجاح، ثم PR صغير يفعل شيئًا واحدًا مع اختباراته (AGENTS §1.2 و§2.1).
2. بنود «تغيير» فقط المرشحة للنقاش مع المالك: نصائح الوصفة، وصفات مشابهة، نسخ النص، النتائج الفارغة الغنية، فرز الشعبية بعد الحي.
3. ما تُصار إليه هنا كله محلي أو وثائقي — لا شبكة ولا كشط في أي PR قادم من هذه الدراسة.
