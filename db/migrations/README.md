# db/migrations — مخطط قاعدة البيانات

هذا المجلد سيضم سكربتات SQL لكل تعديل على مخطط القاعدة، وفق ADR-0004 (قاعدة PostgreSQL، حاليًا فوق Supabase).

## القواعد (إلزامية)

1. لا يعدَّل المخطط إلا عبر سكربت جديد في هذا المجلد، يُدمَج في PR مستقل (أو مع ميزته إن كان جزأً منها).
2. تسمية الملف: تاريخ بالتنسيق `YYYYMMDD` ثم عدد وتسلسل ثم وصف إنجليزية قصيرة — مثل: `20261101_001_recipes_init.sql`.
3. كل سكربت يكون **قابلًا للتشغيل من الصفر** على قاعدة فارغة وصولًا بحالته الأخيرة (إعادة بناء كاملة لا تفشل).
4. المرحلة 1 تضم **هيكلًا فقط** — أول مخطط حقيقي (الوصفات والمستخدمون) يأتي مع المرحلة 2، ويُكتب هنا مع اختباراته.
5. لا أسرار في السكربتات: بيانات الاتصال عبر متغيرات البيئة، وفق AGENTS.md §3.

## الحالة

المجلد فارغ بنيةً عندها. لا مخطط مُفعَّل، ولا اتصال حقيقي بالقاعدة — **لم يُختبر** على قاعدة حية حتى المرحلة 2.
