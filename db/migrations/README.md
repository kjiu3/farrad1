# db/migrations — مخطط قاعدة البيانات

هذا المجلد سيضم سكربتات SQL لكل تعديل على مخطط القاعدة، وفق ADR-0004 (قاعدة PostgreSQL، حاليًا فوق Supabase).

## القواعد (إلزامية)

1. لا يعدَّل المخطط إلا عبر سكربت جديد في هذا المجلد، يُدمَج في PR مستقل (أو مع ميزته إن كان جزأً منها).
2. تسمية الملف: تاريخ بالتنسيق `YYYYMMDD` ثم عدد وتسلسل ثم وصف إنجليزية قصيرة — مثل: `20261101_001_recipes_init.sql`.
3. كل سكربت يكون **قابلًا للتشغيل من الصفر** على قاعدة فارغة وصولًا بحالته الأخيرة (إعادة بناء كاملة لا تفشل).
4. المرحلة 2 أضافت أول مخطط (20261101_001_recipes_init.sql) — recipes + recipe_ingredients + recipe_steps. قابل للتشغيل من الصفر (idempotent) ومُختبَر في CI (وظيفة db-migrations على PostgreSQL 16) ومُختبَر **محليًا** على PostgreSQL 16.15 (ويندوز، منفذ 5433): تطبيق من الصفر + 9 تأكيدات (القيود، الحذف المتتالي، الحدود المتطرفة) + إعادة تطبيق بلا فشل — 2026-11-01.
5. المرحلة 3 أضافت مخطط المجتمع (20261102_001_community_init.sql) — profiles + recipe_comments + recipe_ratings + سياسات RLS (القراءة للجميع، الكتابة لمالكه) وفق [ADR-0009](../../docs/adr/ADR-0009-phase3-accounts.md). على قاعدة PostgreSQL مجردة (محليًا وCI) يُنشأ هيكل أدنى لمخطط `auth` (جدول `users` و`uid()`) تلبيةً لمفاتيح Supabase، ولا يُلمس على Supabase الحي. تأكيداته في `db/tests/community_assertions.sql` (12 تأكيدًا: القيود وFK والحدود 1000/1..5 والمفتاح المشترك وRLS بنيويًا) ومُختبَر محليًا بتطبيق من الصفر + idempotency + إعادة تأكيد — 2026-11-02. الاختبار السلوكي الفعلي للسياسات على Supabase الحي يظل «لم يُختبر بعد» (تركباً لـ AGENTS §4.1).
6. كل سكربت يضاف إلى db/migrations يأتي جانبه اختباراته في db/tests بنفس PR (AGENTS §2.1)، ووظيفة CI db-migrations تطبّق كل ملفات المجلد وتفحص كل ملفات db/tests تلقائيًا.
7. لا أسرار في السكربتات: بيانات الاتصال عبر متغيرات البيئة، وفق AGENTS.md §3.

## الحالة

مخطط المرحلة 2 (وصفات/مكونات/خطوات) مُفعَّل ومُختبَر (CI + محليًا 2026-11-01). مخطط مجتمع المرحلة 3 (ملفات شخصية/تعليق/تقييم + RLS) مُفعَّل ومُختبَر بنيويًا (CI + محليًا 2026-11-02)؛ السلوك الحي للسياسات بانتظار مشروع Supabase من المالك (فق ADR-0008 وADR-0009).
